# Consigne

1. A la commande "Revue pédagogique". Utilise le skill `revue-pedagogique` : revue des dossiers /backend et /frontend, produite dans `docs/review/reviewFrontend.md`, `docs/review/reviewBackend.md`, `docs/review/reviewSecurity.md`, `docs/review/reviewTestingLibrary.md`.
2. A la commande "Synthèse des corrections". Utilise le skill `review-to-issues` (mode synthèse) : regroupe les points des fichiers `docs/review/review*.md` dans `docs/corrections.md`. Ne crée aucune issue.
3. A la commande "Crée les issues". Utilise le skill `review-to-issues` (mode issues) : crée les issues GitHub à partir de `docs/corrections.md` après ma validation, puis reporte les numéros dans le fichier.
4. A la commande "Mets à jour LEARNING". Utilise le skill `maj-learning` : met à jour `../docs/LEARNING.md` (compétences, vigilance, registre) à partir des revues, de `docs/corrections.md` et des issues fermées, puis `SESSIONS.md` et `MEMO.js`.
